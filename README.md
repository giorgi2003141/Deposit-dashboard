# Deposit-dashboard
Deposit Portfolio Dashboard
📌 პროექტის აღწერა

ეს პროექტი წარმოადგენს ინტერაქტიულ Power BI Dashboard-ს, რომელიც შექმნილია ბანკის დეპოზიტების პორტფელის ანალიზისთვის. Dashboard უზრუნველყოფს პორტფელის ზომის, სტრუქტურისა და ფინანსური მაჩვენებლების ვიზუალიზაციას, რაც ხელს უწყობს მონაცემებზე დაფუძნებული გადაწყვეტილებების მიღებას.

🎯 პროექტის მიზანი
პროექტის მიზანია:
დეპოზიტების პორტფელის სრული ხედვის შექმნა
მომხმარებლების, ვალუტების და სეგმენტების მიხედვით ანალიზი
პორტფელის ფინანსური ეფექტიანობის შეფასება
დროში პორტფელის დინამიკის მონიტორინგი

📈 ძირითადი მაჩვენებლები (KPI)

Dashboard მოიცავს შემდეგ ძირითად ფინანსურ მაჩვენებლებს:

💰 Total Deposits – დეპოზიტების ჯამური მოცულობა
👥 Total Customers – მომხმარებლების რაოდენობა
🏦 Total Accounts – ანგარიშების რაოდენობა
📊 Average Deposit – საშუალო დეპოზიტი ერთ მომხმარებელზე
🧩 ანალიზის მიმართულებები

Dashboard საშუალებას იძლევა პორტფელის ანალიზი შემდეგ ჭრილებში:
ვალუტის მიხედვით (Currency Distribution)
მომხმარებლის სეგმენტის მიხედვით (Retail / SME / Corporate)
დეპოზიტის ვადიანობის მიხედვით (Term Segment)
სქესის მიხედვით (Gender Analysis)
საბავშვო და არასაბავშვო დეპოზიტები
დროითი ტრენდი (Monthly Trend)

🛠 გამოყენებული ტექნოლოგიები

Power BI – მონაცემების ვიზუალიზაცია და Dashboard
DAX – ფინანსური მაჩვენებლების გამოთვლა
SQL – მონაცემთა მოდელირება
Power Query – მონაცემთა ტრანსფორმაცია

📊 პროექტის შედეგი
